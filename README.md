# 바닷속 물고기 🐟

수천 마리 물고기 떼 속을 헤엄쳐 다니는 3D 바닷속 장면 (three.js).

- 컴퓨터: 화면 클릭 → 마우스로 둘러보기, **W A S D** 헤엄치기, **Space / Shift** 위·아래, **F** 빠르게, **C** 네온 색 전환
- 휴대폰: **폰을 움직여** 둘러보기(자이로), 화면 끌기로 방향 돌리기, 화면을 **꾹 누르고 있으면** 보는 방향으로 헤엄(위를 보면 위로),
  화면 **두 번 톡** → 출처·정면 버튼 (아이폰은 처음 터치할 때 뜨는 '동작 및 방향 접근' 창에서 허용을 눌러 주세요)
