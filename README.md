# 바닷속 물고기 🐟

수천 마리 물고기 떼 속을 헤엄쳐 다니는 3D 바닷속 장면 (three.js).

- 컴퓨터: 클릭해서 시작 → 마우스로 둘러보기, **W A S D** 헤엄치기, **Space / Shift** 위·아래, **F** 빠르게, **C** 네온 색 전환
- 휴대폰: 탭해서 시작 → **폰을 움직여** 둘러보기(자이로), 화면 끌기로 방향 돌리기, 왼쪽 **조이스틱**으로 헤엄(두 번 톡 → 빠르게), 오른쪽 **위로·아래로** 버튼
  (아이폰은 '동작 및 방향 접근' 창에서 허용을 눌러 주세요)
